# 삼성 유니버설 제스처 수집 (#41)

삼성 유니버설 제스처(핀치, 주먹 쥐기 등)가 **인식된 순간의 센서 값**을 모으는 도구다.
삼성이 "이건 제스처다"라고 판단한 데이터를 보고, 우리 제스처 인식 기준을 잡는 데 참고한다.

## 원리

1. 삼성 접근성 앱은 유니버설 제스처를 인식할 때마다 워치 로그에 **시각과 동작**을 남긴다.
   ```
   1795742707.790 ... I WUG::ActionManagerImpl: action performed : NEXTITEM
   ```
2. 워치 앱의 **"삼성 제스처 수집"** 화면은 가속도·자이로(약 100Hz)와 심박 원시 신호(PPG, 약 25Hz)를
   **실제 시각**과 함께 계속 기록한다. (`session__*.csv`)
3. 수집이 끝나면 PC가 워치 로그 버퍼를 꺼낸다. (`adb logcat -d`)
4. PC 도구(`tools/samsung_gesture_labeler.py`)가 인식 시각에 맞춰
   **인식 1.5초 전 ~ 0.3초 후** 센서 값을 잘라 라벨을 붙이고, 제스처별로 요약한다.

수집하는 동안 **PC가 연결돼 있지 않아도 된다.** 워치는 충전 중이거나 폰과 블루투스로 연결되면
Wi-Fi를 꺼서 무선 디버깅이 자주 끊긴다. 그래서 실시간으로 받지 않고, 끝난 뒤 로그 버퍼를 꺼낸다.
로그 버퍼는 기본 1MB(몇 분치)라서, 수집 전에 16MB(1시간쯤)로 키워 둔다.

> 워치 앱이 직접 로그를 읽는 방법은 안 된다. 안드로이드 13부터 다른 앱의 로그를 읽으려면
> READ_LOGS 권한에 더해 사용자 확인 창이 필요한데, 이 워치에서는 확인 창 없이 거부된다.
> (READ_LOGS를 줘도 앱에는 자기 로그 441줄만 보였다. 전체는 3만 줄 이상)

| 로그의 동작 | 제스처 (팀 워치 설정) | 라벨 |
|---|---|---|
| `NEXTITEM` | 엄지 검지 맞대기 | `pinch` |
| `PREVITEM` | 엄지 검지 두 번 맞대기 | `double_pinch` |
| `TAP` | 주먹 쥐기 | `fist` |
| `SHOW_ACTION_MENU` | 주먹 두 번 쥐기 | `double_fist` |
| `BACK` | 팔 앞뒤로 | `arm_back_forth` |
| 활성화 `OCO2` | 손목 두 번 흔들기 | `activation_oco2` |

워치 설정에서 제스처의 동작을 바꿨다면 `--map 동작=제스처`로 대응을 바꾼다.

> **한계**
> - 삼성 내부 판단 기준(임계값, 모델)은 볼 수 없다. 얻는 것은 "인식됐을 때의 센서 값"이다.
> - 로그 형식은 삼성 접근성 앱 15.0.00.30 기준이다. 업데이트되면 바뀔 수 있다.
> - 인식 시각은 동작이 **끝난 뒤**라서, 그 앞 1.5초를 잘라낸다. 부족하면 `--before`를 늘린다.

## 준비 (처음 한 번)

1. 워치를 PC와 무선 디버깅으로 연결한다. ([gesture-tool.md](gesture-tool.md) 2절)
2. 워치에 최신 앱을 설치한다: `cd android; .\gradlew :wear:installDebug`
   - 설치 직후 첫 실행은 앱 준비(컴파일) 때문에 30초쯤 느리다. 잠시 기다렸다가 쓴다.
3. 워치 **설정 → 접근성 → 상호작용 및 손재주 → 유니버설 제스처**를 켠다.

## 수집

1. **수집 전 (PC)**: 워치 로그 버퍼를 키운다. 워치를 다시 켜면 원래대로 돌아가므로 수집 전마다 한다.
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\collect_samsung_gestures.ps1 -Prepare
   ```
2. **수집 (워치만)**: **WatchOut 제스처 → 삼성 제스처 수집**을 연다.
   - 처음이면 **신체 센서 권한**을 묻는다. **허용**하면 심박 원시 신호도 기록한다.
   - 손목을 두 번 흔들어 유니버설 제스처를 켜고, 제스처를 **3초쯤 간격**을 두고 한다.
   - 끝나면 화면을 **밀어서 나간다.**
3. **수집 후 (PC)**: 워치 화면을 켜 두고 실행한다. 로그를 꺼내고 최근 세션을 가져와 분석한다.
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\collect_samsung_gestures.ps1
   ```

화면에는 누를 수 있는 버튼이 없다. "주먹 쥐기"가 화면을 탭하기 때문이다.
"뒤로 가기"(팔 앞뒤로)도 무시해서 수집 화면이 닫히지 않는다.

## 결과 보기

```
제스처            개수  최대회전(rad/s)  자이로 X/Y/Z 최대    가속 이탈(m/s²)  심박 변화폭
pinch                7        0.99±0.79       0.86/0.45/0.31        2.02±1.46  2476.71±2035.51
```

- **최대회전**: 인식 전후 회전 속도의 최댓값.
- **가속 이탈**: 가속도 크기가 중력에서 벗어난 최댓값.
- **심박 변화폭**: 심박 원시 신호(채널 1)의 최대-최소. 손가락을 움직일 때 커지면
  삼성이 PPG도 쓸 가능성이 높다.

잘라낸 구간은 `data\samsung\windows__*\samsung_<제스처>__<시각>.csv`로 저장된다.
시간은 인식 순간을 0으로 한 ms다.

### 심박 원시 신호(PPG) 형식 주의

삼성 "HR Raw Sensor"는 **정수 값을 float 배열에 비트 그대로** 넣어 보낸다. 실수로 읽으면
`2.9e-39` 같은 아주 작은 수가 된다. 분석할 때는 비트를 int32로 다시 풀어야 한다
(`decode_ppg()`). 팀 워치에서는 16채널 중 **채널 1~5가 광센서 값**이고, `2097152`(2²¹)는
"값 없음" 표시, 채널 15(83~147)는 심박수로 보인다.

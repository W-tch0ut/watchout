# 폰 앱 보호자 연결·응급 알림·문자 (#50)

환자(본인 모드)와 보호자(보호자 모드)를 **문자로 보낸 초대 코드**로 연결한다.
응급 상황이 확정되면 연결된 보호자 앱에 알림(시각·쓰러짐·움직임·사진)이 뜨고,
등록된 보호자 번호로 **실제 문자**가 간다. **119는 화면 표시(시뮬레이션)만** 한다.

- 코드: `android/mobile` — `link/`(연결), `alert/`(알림), `sms/`(문자), `patient/`(환자 쪽 두뇌), `family/`(보호자 쪽 두뇌)
- 보안 규칙: `firebase/firestore.rules`
- 설계: `docs/uml/mobile-guardian.puml` (클래스 구조, 연결 흐름, 응급 알림 흐름)
- 로그인·연락처·모드는 [mobile-login.md](mobile-login.md)

## 1. 사용 방법 (데모 순서)

1. **환자 폰** — 본인 모드에서 보호자 연락처를 등록한다. (데모에서는 팀원 번호)
2. 연락처의 **[초대 문자]** → 문자 권한을 허용 → 보호자 번호로 6자리 코드 문자가 간다.
   - 권한을 거절했거나 유심이 없으면 화면에 코드를 크게 보여준다. 직접 알려 주면 된다.
3. **보호자 폰** — 보호자 모드 → **[초대 코드 입력]** → 코드 입력 → "○○님과 연결됐어요".
   - 코드는 **10분** 동안, **한 번만** 쓸 수 있다.
   - 환자 폰 연락처에 "✅ 보호자 앱 연결됨"이 뜬다.
4. **환자 폰** — **[테스트 응급 알림 보내기]** → 확인 창 → [보내기]
   - 보호자 앱 "받은 알림"에 바로 뜬다: 시각, 쓰러짐 확인, 움직임 있음/없음, 테스트 사진, 119 시뮬레이션 표시
   - 등록된 보호자 번호 전부에 `[WatchOut 테스트] …` 문자가 간다.
   - 환자 폰에 "🚑 119에 연락했어요 — 시뮬레이션" 창이 뜬다. **실제로 전화·문자하지 않는다.**
5. **보호자 폰** — **[확인했어요]** → "○○님이 확인했어요"로 바뀐다 (다른 보호자에게도 보임).

> 실제 문자는 **유심이 있는 진짜 폰**에서만 나간다. 에뮬레이터는 보내는 척만 한다. 문자 요금은 환자 폰 요금제를 쓴다.

## 2. 저장하는 데이터

| 위치 | 필드 | 설명 |
|---|---|---|
| `invites/{6자리 코드}` | `patientUid`, `patientName`, `guardianId`, `createdAt` | 초대 코드. 10분 유효, 연결하면 지운다 |
| `users/{환자}/links/{보호자 uid}` | `guardianId`, `guardianName`, `inviteCode`, `linkedAt` | "이 보호자는 내 알림을 봐도 돼요" 허락증 |
| `users/{보호자}/patients/{환자 uid}` | `name`, `linkedAt` | 보호자 화면의 "연결된 가족" 목록 |
| `users/{환자}/alerts/{자동 ID}` | `kind`(`fall`), `source`(`test`/`robot`), `moving`, `call119`(`simulated`), `photo`(선택, JPEG ≤ 500KB), `createdAt` | 응급 알림 |
| | `ackedBy`, `ackedByName`, `ackedAt` | 처음 [확인했어요]를 누른 보호자 |

- 사진: 무료(Spark) 요금제에서는 Cloud Storage를 새로 만들 수 없어서, 작게 줄인 JPEG을 알림 문서 안에 넣는다(문서 하나 1MB 제한 → 500KB까지).
- 영상과 센서 원본은 저장하지 않는다. **응급이 확정됐을 때만** 사진 한 장을 넣는다.

## 3. 보안 규칙 요약

| 누가 | 무엇을 |
|---|---|
| 환자 본인 | 초대 코드 만들기(내 연락처 앞으로만), 연결 끊기, 알림 만들기·읽기 |
| 코드를 아는 사람 | 그 코드 하나만 읽기(목록 조회 금지) → 10분 안에 연결 |
| 연결된 보호자 | 그 환자의 알림 읽기, [확인했어요] 필드만 한 번 쓰기, 연결 끊기 |
| 그 밖의 사람 | 아무것도 못 함 |

- 만든 시각은 **서버 시각**으로 검사한다. 폰 시계를 바꿔도 만료를 피할 수 없다.
- 환자가 연결을 끊거나 연락처를 지우면, 그 보호자는 즉시 알림을 못 읽는다 (보호자 화면에 "가족이 연결을 끊었어요").
- 코드가 6자리라 이론상 맞혀 볼 수 있다. 10분 제한과 1회 사용으로 위험을 줄였다. 실제 서비스라면 시도 횟수 제한(서버 기능)이 필요하다.

⚠️ **규칙 파일이 바뀌었다.** Firebase 콘솔 → Firestore → 규칙 탭에 `firebase/firestore.rules` **전체를 다시 붙여넣고 게시**해야 한다.
안 하면 초대·연결·알림이 "권한 없음"으로 실패한다.

## 4. 문자 (SEND_SMS)

- 안드로이드 `SmsManager`로 환자 폰이 직접 보낸다. API 키나 유료 서비스가 필요 없다.
- 보내는 대상은 **환자가 등록한 휴대폰 번호(010 등)뿐**이다. `SmsMessages.isMobileNumber`가 119·112 같은 번호를 막는다.
- 문자에는 쓰러짐과 움직임 여부만 쓴다. 병명·원인은 쓰지 않고, 사진은 문자로 보내지 않는다.
- 번호와 문자 내용은 로그(Logcat)에 찍지 않는다.
- 문자 권한은 Google Play 정책상 기본 문자 앱만 쓸 수 있다. 이 앱은 스토어에 올리지 않고 직접 설치(데모용)하므로 괜찮다.

## 5. 아직 안 된 것 (다음 이슈)

- **FCM 푸시**: 지금은 보호자 앱이 켜져 있을 때 실시간으로 보인다. 앱이 꺼져 있어도 알림이 오게 하려면 FCM과 보내는 서버가 필요하다.
- **로봇카 연결**: 로봇카가 워치 충격 + 카메라로 쓰러짐을 확정하면 `users/{환자}/alerts`에 `source: "robot"` 알림을 만들고, 환자 폰이 그걸 보고 문자를 보내게 한다.
- 만료된 초대 코드 문서 자동 정리
